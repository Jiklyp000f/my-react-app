## :dart: О проекте ##

**AutoNexus** — демонстрационный проект, созданный для презентации навыков фронтенд-разработчика после года интенсивного обучения. Проект реализован на современном стеке React + TypeScript и представляет собой платформу для автолюбителей, интересующихся тюнингом автомобилей.

### Ключевые цели проекта:
- 🎓 Демонстрация освоенных технологий и лучших практик разработки
- ⚡️ Реализация полноценного SPA-приложения с клиентской маршрутизацией
- 🛠️ Практическое применение React-паттернов и TypeScript-типизации
- 🔄 Интеграция с внешними API для работы с данными

Проект имитирует работу реального веб-приложения с акцентом на:
- Чистоту и поддерживаемость кода
- Отзывчивый и современный UI/UX дизайн
- Оптимизацию производительности


## :sparkles: Возможности ##

:heavy_check_mark: **Динамическое получение данных** - интеграция с JSONPlaceholder API для получения информации о товарах  
:heavy_check_mark: **Слайдер товаров** - реализация Swiper-слайдера для показа актуальных товаров  
:heavy_check_mark: **Многостраничная структура** - реализация роутинга между разделами сайта 

### Особенности реализации
:gear: **Система переиспользуемых компонентов** - баннеры, кнопки
:triangular_ruler: **Адаптивная верстка** - корректное отображение на всех устройствах  
:zap: **Оптимизация производительности** - lazy loading, code splitting  
:art: **Кастомизация интерфейса** - единая дизайн-система в тематике тюнинга авто  

### Навигация
:world_map: **Главная страница** - основной контент 
:card_index: **Каталог отзывов** - сетка карточек  
:warning: **Страница 404** - кастомная страница для несуществующих маршрутов  

## :rocket: Технологии ##

В проекте использованы следующие технологии:

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/) (или [Webpack](https://webpack.js.org/))
- [React Router](https://reactrouter.com/)
- [Prettier](https://prettier.io/) + [ESLint](https://eslint.org/)

## :white_check_mark: Требования ##

Перед началом работы убедитесь, что установлены:

- [Node.js](https://nodejs.org/) (версия 18+)
- [npm](https://www.npmjs.com/) (версия 9+) или [Yarn](https://yarnpkg.com/) (версия 1.22+)
- [Git](https://git-scm.com/)

## :checkered_flag: Запуск ##

# Клонировать репозиторий
$ git clone https://github.com/Jiklyp000f/my-react-app.git

# Перейти в директорию проекта
$ cd .\my-react-app\react-app\

# Установить зависимости
$ npm install

# Запустить dev-сервер
$ npm run dev

# Собрать production-версию
$ npm run build

# Запустить линтеры
$ npm run lint

# Отформатировать код
$ npm run format
